# Project Memory

## Objetivo

Mantener decisiones importantes del proyecto sin repetirlas constantemente.

## Debe registrar

- decisiones de arquitectura
- estructura actual de Sheets
- funciones implementadas
- limitaciones conocidas
- problemas pendientes
- decisiones descartadas

## Formato

Cada decisión importante debe documentarse brevemente:

### DEC-001

Problema:
...

Alternativas:
...

Decisión:
...

Motivo:
...

Fecha:
...

## Regla

Antes de tomar una decisión arquitectónica importante, revisar las decisiones existentes.

No repetir decisiones ya tomadas salvo que exista nueva información.
